HOW IT ADDRESSES THE PROBLEM
• Pools compatible LTL harvest loads to reduce per-unit freight.
• Compares destinations using expected net realization, not price alone.
• Matches cargo to vehicle capacity and route constraints.
• Re-evaluates decisions when delay/risk conditions change.
INNOVATION & UNIQUENESS
• ENR engine: market value minus logistics and expected quality-loss costs.
• Deterministic CVRP-based pooling and vehicle assignment.
• Voice-first interaction with local-language support.
• Offline-tolerant workflow for patchy rural connectivity.
• One platform for Farmer • Driver • Fleet • Admin.
Our differentiation: the agricultural decision layer combining MARKET + TRANSPORT + TIME + QUALITY + RISK → ENR.

FEASIBILITY, RISKS & MITIGATION
FEASIBLE NOW
• Web/PWA-based client
• Offline-tolerant local persistence
• OpenStreetMap + Leaflet mapping
• OSRM routing with fallback
• Deterministic CVRP prototype
• Browser voice interaction
• Local + VPS deployment
• Modular provider architecture
CHALLENGES / RISKS
• Unstable rural connectivity
• Incomplete or delayed market data
• Voice accuracy across dialects/noise
• Vehicle availability can change
• Large-scale optimization complexity
• User adoption / digital literacy
MITIGATION
• Offline queue + sync when online
• Source validation + timestamps + fallback
• Speech + confirmation + manual input
• Recalculate ENR when conditions change
• OR-Tools / dedicated solver at scale
• Voice-first + minimal input workflows
Feasibility principle: prove the core workflow locally first, then replace individual providers with live services without rewriting the decision layer.
